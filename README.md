# RAG Chatbot

A simple **Retrieval-Augmented Generation (RAG) chatbot** built with Python and LangChain.

## Tech Stack

* Python
* LangChain
* DeepAgents
* OpenAI
* UV

## Setup

Clone the repository:

```bash
git clone <repository-url>
cd rag-chatbot
```

Install dependencies:

```bash
uv sync
```

Create a `.env` file:

```env
OPENAI_API_KEY=your_api_key
```

## Run

```bash
uv run python main.py
```
